## Single Cell Metagenome simulator

This Rust program simulates reads to a hacked BED file format (called the .tirp-format). One also gets a metafile with information regarding each cell_id present in the tirp file.

Requires
-rust toolchain: https://rustup.rs/
-Datasets: https://www.ncbi.nlm.nih.gov/datasets/docs/v2/command-line-tools/download-and-install/
-bgzip from htslib: https://www.htslib.org/download/
